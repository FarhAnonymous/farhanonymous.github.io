# Mohammad Farhan: portfolio

Static site for GitHub Pages. No build step.

## Publish
1. Create a **public** repo named exactly `FarhAnonymous.github.io` (your GitHub username + `.github.io`).
2. Upload everything in this folder to the repo root (index.html, style.css, assets/).
3. Settings → Pages → Source: "Deploy from a branch" → `main` / root.
4. Live at https://farhanonymous.github.io within a minute or two.

## Before you send it to anyone
- Add a headshot as `assets/photo.jpg` (square, about 400x400). Until then the page shows "MF" initials.
- Replace `assets/Farhan_CV.pdf` whenever the CV changes.
- Update "Last updated" in the footer.
